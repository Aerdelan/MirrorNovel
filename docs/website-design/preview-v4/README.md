## 截图配置

- 首屏大图：题材与人设；可切换写作风格、我的书架。
- 风格设置：大图配简短说明。
- 文本润色：大图配简短说明。
- 模型线路：宽幅截图，下方保留个人模型和作者提供模型两种入口。
- 每张截图支持点击放大、查看原图、关闭及 Escape 返回。首屏标签支持键盘方向键切换。

assets 内五张软件截图直接复制自项目 `promo-video/frames/`，未使用生成式图片重绘界面。页面对截图的显示边缘做了排版裁切；放大层与原图入口展示完整原图。截图反映录制时的软件状态，正式发布前应按当前版本重新核对。
