# 章末大段重复修复（2026-10-27）

用户报告：《现实·行业职场：刘海柱的传奇》从书架“继续生成”后，多章重复“写日报、十点半、日子还长慢慢熬吧”的数百字结尾。已将用户提供的文本加入隔离回归测试。

## 原有缺口

整章相似度检查很容易漏过长章节末尾的一小段复制；既有章末形式轮换属于提示约束，没有提交前的独立硬检查。专家模式还可能因为本地评分通过而跳过审稿。未取得线上各章和实际模型请求记录，不能仅凭该缺口确定具体是哪一轮模型请求首次复制了结尾。

## 新行为

- 对比本章与所有已完成前章的末尾 1800 个字符。忽略标点、空格和换行后，连续相同文字至少 100 字即命中；短对白、姓名和少量用词相同不触发。
- 新建生成、书架继续生成、导入续写、指定章节续写均执行检查，无须开启专家模式；正式提交前再次检查最终格式化文本。
- 命中后仅请求一次有长度预算和超时的结尾修订，保持此前正文；指定章节追加只能修改新增部分。修订须满足长度要求且再次通过重复检查。修订失败、仍重复或被截断时暂停，保留断点草稿和已完成章节，不继续生成下一章。
- 没有重复的章节不增加模型调用。修订调用的实际用量纳入作品及本章 token 账本。
- 提示中提供最近三章各最多 500 字收尾作为禁止复制的历史资料，要求从已有事件的后果继续推进。

检测针对文字复制，不能保证识别仅有情节结构相同、但措辞完全不同的章节；模型是否保留全部事实仍需实际正文审读。已保存历史正文不会被批量删除或改写。
