# 连续创作中断修复（2026-11-16）

本次修复覆盖桌面端共用的创作页、任务恢复、Electron SSE 代理，以及后端创建/继续/导入续写/指定章节续写。测试使用隔离数据及模拟模型，没有调用真实付费模型或修改用户作品。

## 原因与处理

- 桌面代理没有处理响应中途断流：补充上游 aborted/error 与订阅释放，避免假正常结束或一直挂起。
- 创作页断流后立即退出生成状态：改为只读查询持久任务；queued/running/pause_requested 都保持跟踪，查询暂时离线不视为暂停，不重复提交生成 POST。已提交章节增长时最多每 5 秒刷新正文，完成时重读最终结果。
- 刷新和重新编辑：保存原始输入及普通/轻小说界面类型；恢复时保留任务锁，过期响应不能覆盖新任务或其他账号页面。
- 正文流已经输出一部分后失败：先持久化草稿，再在同任务、同章节从草稿尾部续接，最多两次。没有新增正文、不具备可恢复标志、主动暂停、保存失败或丢失任务租约均不自动重试。
- 正文已保存后，辅助语义记忆失败导致整本停止：保留已验证记忆，以明确标注的近期已保存正文摘录补足下一章上下文，并在下一章节边界重新整理。JSON 外层代码块、缺省可选索引可兼容，证据真实性和必要事件校验仍保留。存储失败和主动取消仍中断。
- 章节计划只返回一小批或实际章长低于预计：在已有大纲和有效计划基础上补足执行卡；在已提交章节的计划边界按实际章长重新计算，单次请求最多追加三批。无大纲/有效计划、详细计划持续无效、重复章末或硬约束不通过时仍明确暂停并保留草稿。
- 每次正文调用结束清理思考心跳，避免跨章累积定时器。
